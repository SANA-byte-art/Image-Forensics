FORENSIX AI

Advanced Image Forensics Detection System

Project Overview

FORENSIX is a deep learning based image forensic system developed as a Postgraduate research project. The system detects whether an image is AI-generated, manipulated, or authentic using Convolutional Neural Networks.

The platform integrates machine learning, digital forensics principles, and modern web technologies to provide real-time image authenticity verification with confidence scoring.

The system is implemented using Flask for the backend, TensorFlow/Keras for model inference, and a modern dark UI for visualization and analytics.

Technical Architecture

CNN Architecture

3-layer convolutional neural network with filters (32 → 64 → 128) with pooling and dropout.

Feature Fusion

Hybrid feature extraction combining spatial and frequency domain forensic signals.

Dataset

Dataset includes AI generated, manipulated, and real images for robust training.

Classification

Softmax output providing 3-class prediction with confidence probabilities.

Framework

Built using TensorFlow / Keras with Adam optimizer and categorical cross-entropy loss.

Performance

Model achieves ~96% accuracy with real-time inference capability.
